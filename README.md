# 明日方舟 · 阿米娅 — 星露谷物语 Mod（测试版）

> 这是一个**测试性 / 开发中**的 Mod：将《明日方舟》中罗德岛的公开领袖 **阿米娅（Amiya）** 作为可恋爱自定义村民引入《星露谷物语》。

## ⚠️ 当前状态：仅完成逻辑部分

本 Mod 目前**只实现了数据逻辑层**，**尚未处理精灵（Sprite）动画与美术素材**。具体进度如下：

### ✅ 已完成（逻辑部分）
- **角色注册**：阿米娅作为可恋爱自定义村民（`Data/Characters`），含显示名、性别、年龄、生日（冬 23，对应角色设定 12/23）、礼貌 / 积极性格等
- **对话系统**：初次见面、周一至周日日常对话、玩家与其他村民约会时的反应
- **结婚对话**：室内 / 室外 / 雨天 / 夜晚四组婚后台词
- **日程系统**：春 / 夏 / 秋 / 冬四季日程
- **好感系统**：礼物偏好（最爱宝石、喜欢水果、不擅长料理）、订婚对话
- **据点**：自定义房屋「阿米娅的家」及其在小镇的传送入口

### ❌ 未完成（待进一步开发）
- **精灵动画与美术素材**：当前 `sprites.png` / `portraits.png` 等美术资源为**占位 / 临时替换素材**，**未对阿米娅做任何帧动画、行走动画、表情动画或立绘动画的适配**。这部分需要等待进一步的美术开发。
- 好感度事件（Heart Events）脚本尚未编写
- 节日对话、特殊场景对话尚未补全

## 依赖
- 《星露谷物语》**1.6 或以上**
- [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915)（由 Pathoschild 提供，作为本 Mod 的内容补丁加载器）

## 安装
1. 安装 SMAPI 与 Content Patcher。
2. 将本仓库的 `new npc/` 文件夹整体放入游戏的 `Mods/` 目录。
3. 启动游戏，阿米娅会出现在小镇她自己的家中。

## 目录结构
```
new npc/
├── manifest.json             # Mod 清单（名称 / 作者 / 依赖）
├── content.json              # Content Patcher 修改清单（角色 / 房屋 / 礼物等）
└── assets/
    ├── sprites.png           # 村民精灵（占位素材，待美术动画）
    ├── portraits.png         # 对话立绘（占位素材，待美术）
    ├── dialogues.json        # 日常 / 初次见面对话
    ├── MarriageDialogue.json # 婚后台词
    ├── schedules.json        # 四季日程
    ├── HinataHouse.tmx       # 房屋内部地图（美术待替换）
    ├── HinataExteriorHouse.tmx # 房屋外观地图（美术待替换）
    └── *.png                # 其余 tilesheet 与贴图素材
```
